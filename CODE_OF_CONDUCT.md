# Code of Conduct

We want MochiLife to be a respectful, harassment-free project for everyone,
regardless of age, disability, ethnicity, gender identity, experience,
nationality, religion, language or background.

**Expected:** be kind and patient, assume good faith, give and accept
constructive feedback, and focus on what is best for the people who use the app.

**Not acceptable:** harassment, insults, discriminatory language or jokes,
personal attacks, publishing someone's private information, or sexualised content.

Maintainers may remove comments, commits or contributions that break this code
and may block repeat offenders. To report a problem, use the repository's
private "Report a vulnerability / contact" channel or open a private security
advisory on GitHub; reports are handled confidentially.

This code is adapted from the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
