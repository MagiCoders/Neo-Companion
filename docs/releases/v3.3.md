# MochiLife 3.3 (pre-release)

A voice-first AI companion for Android. **Pre-release: tested on one phone (Samsung Galaxy S22+). Not yet evaluated with assistive-technology users.**

## Highlights
- On-phone mode: Whisper listens, Gemma answers, no internet needed (slower than cloud; "Automatic" is recommended).
- Wake-phrase detector fix, echo guard so she does not hear her own voice, less wasted work in phone mode.
- Diagnostics: "Last close" report and app trail explain why the app last closed. No speech is recorded.
- Removed the experimental Piper test voice and all GPL code (the project is Apache-2.0).

## Install
Download the APK below, allow installs from your browser or file manager when Android asks, and open it. Android 7.0 or newer. Requires your own build for Firebase-backed cloud features (see README: bring your own Firebase project).

## Verify
SHA-256 of the APK is listed in the release description. Compare it with `sha256sum MochiLife-3.3.apk`.
